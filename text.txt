Enter the Postgres database (inside the container)

From your terminal:

docker exec -it reachinbox-postgres psql -U reachuser -d reachinbox


If successful, you’ll see:

reachinbox=#


This means you are inside the database.

2️⃣ List all tables (sanity check)
\dt

You should see something like:

 public | emails | table | reachuser


This confirms the table exists.

3️⃣ See the table structure (columns)
\d emails



View all email records (data)
SELECT * FROM emails;


This will show:

which emails are scheduled

which are sent

timestamps for both

If the table is empty, you’ll see:

(0 rows)

5️⃣ View only scheduled emails (very useful)
SELECT id, recipient_email, scheduled_at, status
FROM emails
WHERE status = 'scheduled';

6️⃣ View only sent emails
SELECT id, recipient_email, sent_at, status
FROM emails
WHERE status = 'sent';

7️⃣ Exit Postgres cleanly
\q
